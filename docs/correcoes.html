Nenhum pipeline automatizado é infalível. Aqui está como reportar uma imprecisão e o que acontece depois que ela é confirmada.

Última atualização: 29/09/2026

Como reportar um erro

Se você encontrar uma notícia mal classificada, um dado incorreto, uma tradução com problema ou qualquer outra imprecisão, o canal mais rápido é o grupo do Telegram — descreva o item (link ou horário) e o que está errado.

O que fazemos quando um erro é confirmado

Hoje esse processo é manual: revisamos o item reportado contra a fonte original e, se o erro for confirmado, corrigimos o dado subjacente (arquivo publicado no site) o mais rápido possível. Quando o erro está numa mensagem já enviada ao canal do Telegram, publicamos uma correção como mensagem nova referenciando a original — o Antes do Sino não edita silenciosamente uma mensagem já publicada sem deixar rastro de que houve correção.

Não existe ainda um índice público automatizado de correções (um "changelog" de erratas) — é algo que pretendemos evoluir conforme o produto cresce. Até lá, a transparência sobre uma correção específica passa pelo canal do Telegram.

Diferença entre erro e conteúdo sinalizado como incerto

Nem toda imprecisão é um "erro" no sentido de bug: notícias marcadas com a etiqueta RUMOR já avisam que a informação não estava confirmada no momento da publicação, e sínteses geradas por IA que não puderam ser verificadas contra a fonte caem automaticamente num texto de aviso em vez de serem publicadas como fato (ver Metodologia e fontes). Correção, aqui, é reservada pra quando o sistema publicou algo que está objetivamente errado.
