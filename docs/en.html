Automated Brazilian
market news, done right.

Antes do Sino is a solo-built pipeline that reads Brazilian financial news feeds, classifies them with an LLM, and publishes to Telegram and a static site — built as a portfolio piece for market-intelligence, IR, research and sales-trading roles, with an explicit bias toward rigor over growth.

This page is a static English summary for reviewers. The live product itself — news, market temperature, the derivatives simulator — is in Portuguese, because it covers the Brazilian market and every source it reads is Brazilian. The problem

Retail-facing financial content in Brazil tends toward two failure modes: an unfiltered firehose of headlines with no materiality signal, or oversimplified "buy/sell" calls with no transparency about where a number came from. Antes do Sino is built against both — an automated editorial pipeline that scores what actually matters, tags what's confirmed versus rumored versus opinion, and never generates a number that isn't traceable to its source.

How it works

IngestionPython pipeline polling public RSS feeds (Reuters, Bloomberg, InfoMoney, and others) plus forwarded Telegram channels, running every few minutes via GitHub Actions.

ClassificationA single LLM call (Groq/Llama) per item scores materiality, sentiment, and content type (fact/opinion/interview/unconfirmed) — then a separate, deterministic check compares every number in any generated text against the source text and drops anything that doesn't match, before it can ever be published.

PublicationTime-boxed digests (pre-market, midday, close, night wrap) sent to Telegram, plus a fully static site (vanilla HTML/CSS/JS, no framework, no build step) deployed to GitHub Pages.

What the live site includes

Radar de Abertura (home) — market temperature, essential indicators, curated news with asset/sector tags, and a daily agenda, with the headline message itself adapting to the time of day (pre-open / session / after-close / weekend). Terminal — the full dashboard: indices, FX, commodities, a customizable panel layout. Derivatives simulator — bull call spread, bear put spread, collar and protective put, with a live payoff chart computed entirely client-side (no options-chain data dependency, since no free real-time source exists for that in Brazil). Plus a heatmap, a quant screener, and a full methodology/legal section (sourcing, correction policy, privacy, cookies, risk disclaimer).

Engineering choices worth calling out

No framework, on purposeEvery page is hand-written HTML/CSS/vanilla JS — free hosting on GitHub Pages, zero build pipeline, and a design system (tokens, dark/light themes) shared as one CSS file across every page.

Fail honest, never inventWhen a data point isn't available (no free source, a stale feed, a failed fetch), the interface says so explicitly instead of guessing — the same rule that governs the anti-hallucination check on AI-generated text.

Performance without a rewriteEvery TradingView widget on every page goes through one shared mount function, which was enough to add IntersectionObserver-based lazy loading site-wide with a single, isolated change.
